# 📅 Schedule Desktop

Виджет расписания для ПК. Показывает время, дату и остаток до конца пары.

## 🚀 Установка

### Способ 1: Готовый .exe
1. Открой [Releases](../../releases)
2. Скачай Schedule.exe
3. Запусти

### Способ 2: Собрать сам
1. Установи Python 3.13
2. Запусти build.bat
3. Готовый .exe в папке dist/
