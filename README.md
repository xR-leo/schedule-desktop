# 📅 Schedule Desktop

Виджет расписания для ПК (Windows). Показывает текущую пару, часы и сколько осталось до конца. Настройка цветов, радуга времени, темы (Неон, Ретро, Минимал). Работает поверх всех окон, не грузит систему.

---

## 🚀 Быстрый старт

### Способ 1: Готовый .exe (самый простой)

**Для кого:** Кто не хочет возиться с Python.

1. Открой **[Releases](../../releases)**
2. Скачай **`Schedule.exe`** (последняя версия)
3. **Перетащи** `Schedule.exe` в **отдельную папку** (например, `Документы\Schedule\`)
4. **Двойной клик** по `Schedule.exe`
5. Если Windows ругается:
   - Нажми **«Подробнее»**
   - Потом **«Выполнить в любом случае»**
6. Виджет появится на экране ✅
7. Рядом с `.exe` создастся папка **`data`** — там хранятся настройки

**Готово!** 🎉

---

### Способ 2: Собрать сам (нужен Python)

**Для кого:** Кто хочет собрать `.exe` сам или изменить код.

#### Шаг 1: Установи Python

1. Открой **[python.org/downloads](https://python.org/downloads)**
2. Скачай **Python 3.13** (кнопка **Download Python**)
3. **Запусти установщик**
4. ⚠️ **ВАЖНО:** поставь галочку **«Add Python to PATH»** внизу окна
5. Нажми **«Install Now»**
6. Жди 1–2 минуты
7. Нажми **«Close»**

#### Шаг 2: Скачай репозиторий

1. На странице репозитория нажми **зелёную кнопку `Code`**
2. Выбери **«Download ZIP»**
3. Распакуй архив в удобное место (например, `Документы\Schedule\`)

#### Шаг 3: Запусти сборку

1. Открой папку с распакованным архивом
2. Найди файл **`build.bat`**
3. **Двойной клик** по нему
4. Появится **чёрное окно** — не закрывай его!
5. Скрипт:
   - Проверит Python
   - Установит библиотеки (PyQt5, psutil, pyinstaller)
   - Соберёт `.exe`
   - Очистит мусор
6. Жди **1–3 минуты**
7. Когда появится **«ГОТОВО!»** — откроется папка `dist`
8. Внутри — **`Schedule.exe`** ✅

#### Шаг 4: Запусти

1. **Двойной клик** по `dist\Schedule.exe`
2. Виджет появится на экране ✅

## 🎨 Настройка

### Как открыть настройки

1. **ПКМ** (правая кнопка мыши) по **иконке в трее** (возле часов)
2. Выбери **⚙️ Настройки**

### Что можно настроить

| Вкладка | Что настраивается |
|---------|-------------------|
| **🎨 Фон** | Цвета фона, прозрачность, скругление |
| **✏️ Время** | Размер часов, цвет, радуга, градиент |
| **✨ Эффекты** | Тень, обводка, пульсация, темы |
| **📚 Расписание** | Свои пары и звонки |
