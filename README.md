## ❓ Частые проблемы

### 🔴 Windows ругается при запуске .exe

**Решение:**
1. Нажми **«Подробнее»**
2. Потом **«Выполнить в любом случае»**

Это нормально для новых `.exe` без цифровой подписи.

### 🔴 `build.bat` закрывается сразу

**Решение:**
1. Открой **CMD** (Win+R → `cmd`)
2. Введи: `cd путь\к\папке`
3. Введи: `build.bat`
4. Окно не закроется — увидишь ошибку
5. Проверь файл `build_log.txt` — там всё записано

### 🔴 Ошибка «Python не найден»

**Решение:**
1. Переустанови Python
2. ⚠️ Поставь галочку **«Add Python to PATH»**
3. Перезапусти CMD

### 🔴 Виджет не появляется

**Решение:**
1. Проверь **трей** (возле часов) — там должна быть иконка
2. ПКМ по иконке → **«Показать виджет»**
3. Если иконки нет — запусти `.exe` **от администратора**

### 🔴 Настройки не сохраняются

**Решение:**
1. Проверь, что папка `data` есть рядом с `.exe`
2. Если нет — создай вручную
3. Проверь права на запись в папке
