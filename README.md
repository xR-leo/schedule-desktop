# 📅 Schedule Desktop

Виджет расписания для ПК (Windows). Показывает время, дату и остаток до конца пары. Работает поверх всех окон.

---

## 🚀 Установка

### Способ 1: Готовый .exe

1. Открой **[Releases](../../releases)**
2. Скачай **`Schedule.exe`**
3. Перетащи в отдельную папку (например, `Документы\Schedule\`)
4. **Двойной клик** по `Schedule.exe`
5. Если Windows ругается — **«Подробнее»** → **«Выполнить в любом случае»**

---

### Способ 2: Собрать сам

1. Скачай **Python 3.13**: [python.org](https://python.org/downloads) (галочка **Add to PATH**)
2. Скачай репозиторий (**Code → Download ZIP**)
3. Распакуй
4. Запусти **`build.bat`** (двойной клик)
5. Жди 1–3 минуты
6. Готовый `.exe` — в папке `dist/`

---

## 🎨 Настройка

**ПКМ по иконке в трее** → **⚙️ Настройки**

| Вкладка | Что настраивается |
|---------|-------------------|
| 🎨 Фон | Цвета, прозрачность |
| ✏️ Время | Размер, цвет, радуга |
| ✨ Эффекты | Тень, обводка, темы |
| 🔔 Звонки | Время пар |

---

## ❓ Частые проблемы

**Windows ругается при запуске .exe**
→ «Подробнее» → «Выполнить в любом случае»

**build.bat закрывается сразу**
→ Открой CMD → `cd путь` → `build.bat`

**Виджет не появляется**
→ Проверь трей → ПКМ → «Показать виджет»
